# 量化研究台 · 前端

只读的中文量化研究结果查看器，使用 React 19、TypeScript 5、Vite 6 与 ECharts 5。页面直接消费后端 `/api/v1`，不包含本地生成的替代数据，也不在页面上发起因子计算或回测任务。

## 运行要求

- Node.js 20 或更高版本
- 后端服务运行在 `http://127.0.0.1:8000`

开发服务器固定使用 `5173` 端口，并将 `/api` 代理到后端；生产构建产物可由 FastAPI 后端同源托管。

## 命令

```bash
cd frontend
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5173
npm run typecheck  # TypeScript 类型检查
npm run build      # 类型检查并构建到 dist/
npm run preview    # 预览构建产物 http://127.0.0.1:4173
```

## 页面

- **股票因子**：选择评分批次与股票，查看原始值/百分位得分、评分元数据与历史评分走势。
- **因子排名**：按后端字段排序并分页展示横截面排名，点击股票可跳转至股票因子页。
- **回测结果**：查看已保存回测的指标、净值/基准、回撤、持仓、成交、配置与限制，并从后端下载结果 JSON。

所有因子值与回测结果均来自后端接口；数据为空、指标为 `null` 或请求失败时，界面会明确展示对应状态，不会用前端模拟数据填充。
