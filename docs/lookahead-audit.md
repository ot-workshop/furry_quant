# 避免未来函数

回测引擎不会自动保证输入数据和策略没有未来信息。项目从数据版本、信号时间、成交时间和结果复现四个层面限制未来函数。

## 基本原则

1. 信号只能读取决策时点已经可用的数据。
2. 收盘计算的信号最早在下一交易日执行。
3. 未来收益只作为评估标签，不进入评分。
4. 历史数据修订不会覆盖旧研究绑定的不可变输入。
5. 不能证明历史可得时间的字段明确标记为未认证。

## 行情输入

- 每只股票必须与声明的交易日历对齐，重复和意外缺口拒绝。
- 非法 OHLC、复权尺度突变和来源冲突不会静默修补。
- 停牌与缺失分开处理；缺失开盘价不回退使用当日收盘价。
- 当日最终成交量不用于开盘订单容量判断。
- 当日收盘涨跌幅不用于预判当日开盘是否可交易。

## 财务与估值

`report_period` 只描述报告期，不能作为可用时间。财务数据需要公告或可用时间和版本信息；选择历史版本时先按查询时点过滤，再选报告期版本。

每日 PE、PB 和市值按交易日对齐并记录观察日期。若供应商没有提供完整历史修订和首次发布时间，程序可以保证不读取未来日期，但不能把它声明为严格 point-in-time 财务数据库。

## 历史股票池与行业

当前成分名单和当前行业不能回填历史。历史成分与历史行业使用各自保存的区间和生效约定；未来新增记录或分类变化不能改变较早日期的研究输入。

固定当前股票池仍存在幸存者偏差，适合比较配置，不等同于无偏历史指数研究。

## 因果性检查

关键计算需要满足：

- 修改未来价格不改变此前因子、成交和净值。
- 修改未来估值或复权不改变此前结果。
- 截断数据后重放，重叠历史结果一致。
- 修改当日收盘不能改变已经发生的当日开盘成交。
- 后续数据修订不会改变旧结果文件和 `dataset_id`。

这些检查证明程序因果性，不证明供应商历史数据本身从未被回写。

## 模型边界

日线回测不提供逐笔竞价、真实分红税、完整退市清算、盘中流动性和订单簿模拟。研究报告应同时展示数据认证状态、执行假设、基准口径和成本参数，不能只展示收益率。
