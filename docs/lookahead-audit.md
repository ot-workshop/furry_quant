# 时间边界与数据风险专项检查

日期：2026-10-18

## 检查结论

前一阶段 7 项验收主要覆盖样本信号滞后、账户对账和结果接口，不能据此声称真实财报不存在未来信息。此次专项增加反例，修正配置与输入边界，并建立独立的财报时点选择函数。

当前仍无真实财报采集链路：样本 ROE/PE 是合成字段，没有真实公告日期和修订历史。新增财报函数及测试提供接入前的约束，尚不能证明第三方供应商历史数据满足这些约束。

## 已复现并修复

| 问题 | 复现与影响 | 当前处理 |
| --- | --- | --- |
| 收盘信息影响当日开盘成交 | 固定评分和开盘价，只将首个交易日收盘价乘 3，原配置会推迟开盘买入。Qlib 的浮点 limit_threshold 用当日收盘涨跌幅判断可交易性 | 样本明确禁用真实涨跌限制，使用基于正开盘价恒为假的限制表达式；收盘扰动测试由失败转为通过 |
| 开盘缺失悄悄回退收盘价 | Qlib 在开盘 NaN、零或负数时可能回退使用当日收盘价 | 导出前拒绝非有限或非正 OHLC，不让不支持的输入进入撮合 |
| 零量日仍成交 | 有效收盘价、成交量为零的样本仍可在 Qlib 默认设置下成交 | 无停牌样本适配器直接拒绝非正成交量；真实行情规则以后单独接入 |
| 缺失日期导致特征错位 | 直接按行写 .bin 且只有一个起始索引，缺某只股票一天时，后续值可能左移到错误日期 | 当前样本必须包含完整声明的日期网格，缺口、重复直接报错，不填零或前向补价 |
| 历史快照被后续导出覆盖 | 默认目录可以被不同代码版本的样本导出复用 | 特征目录增加运行指纹子目录，结果保存对应路径 |

前四项处理限定在明确无停牌、无公司行动的样本适配器中。拒绝数据不是生产停牌处理的实现；不能直接把这个导出器用于真实全市场数据。

## 财报时点规则与验证

实现位置：`src/finance_quant/data/point_in_time.py`。

- `report_period` 只用于确定报告期，不用于决定可见时间。
- 查询时点和 `available_at` 必须带时区；缺失或仅有日期不能直接猜测为当日零点可见。
- 先过滤 `available_at <= as_of`，再对每个标的、报告期选可见版本，最后截取历史窗口。
- 后续修订只影响修订公开后的查询，不回填到更早决策时点。
- 一份旧报告期的新修订不能代替已经公开的更新报告期。
- 只有公告日期时，由调用方提供交易所日历，保守设为下一交易日开盘可用。若策略仅在收盘决策，则仍按下一次决策时刻使用，不在公告当日收盘提前使用。
- 未知可见时间、重复版本、非法版本号、报告期结束前即声称可用等输入明确报错。

适配器仍须确认 `available_at` 的来源，以及公告、更正、重述字段含义。如果第三方只有最新修订值且无原始版本，仅加 `ann_date` 过滤也无法严格重建过去。

## 验证结果

27 项测试通过，包括：

- 未来价格变化不影响更早因子值。
- 前一日评分、下一日开盘成交；修改当天收盘价不改变当天开盘成交。
- 最低费用、整手数量、现金和股数逐日对账及期初本金口径。
- 财报公告前、当日收盘前、修订前后、跨标的独立性及先过滤再截窗。
- 开盘缺失、零量、复权变化、重复和日历缺口的拒绝行为。
- 已有结果不可变、评分版本不混合、接口参数和未完成任务目录。

## 尚待真实数据验收

历史股票池与退市标的、行业变更、ST/板块与日期相关交易规则、开盘涨跌停、真实停复牌、分红送转与复权、财报原始与更正版本、发布时间粒度、数据修订与缺失原因。

全日成交量不能用于预先决定开盘订单数量；全日收盘涨跌幅不能用于预判当日开盘可交易性。Qlib 是回测实现，不自动保证输入数据和所有交易配置都没有未来信息。

## 真实行情接入后的补充验收

上述27项为样本阶段记录。真实行情接入后共73项测试通过，增加了未来价格、估值和复权扰动隔离、拆股财富守恒、开盘涨跌停价判断、显式信号可用时间、完整账户区间和数据来源缓存隔离检查。真实财报没有进入本次因子计算；每日估值18:00可用仍属于假设，供应商历史修订尚待核实。完整范围及公司行动口径见 [真实数据接入记录](real-data-status.md)。

数据管理阶段已增至153项测试。实际多年数据验收另外发现供应商复权尺度异常，新增复权连续性/接口涨跌幅对照检查，发布与加载均拒绝异常候选；数据不会用前向填充或未来基准缩放修补。通过已有区间测试不等于证明供应商全部历史无未来信息，具体证据见[数据问题记录](provider-data-issues.md)。
