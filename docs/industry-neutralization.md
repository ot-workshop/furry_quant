# 历史行业、行业诊断与中性化

## 网页使用

“新建研究 → 因子配置 → 行业中性化”可选关闭或开启，默认关闭。固定快照、下载新股票池及沪深300历史动态池共用同一处理链。任务、草稿、配置导出和“再用此配置”保存开关及行业版本；刷新行业缓存后，可点“使用最新行业数据”切换版本，旧任务保留原版本。

运行后，“个股因子”显示历史行业、原始因子、处理前得分与贡献、标准化行业残差、处理后得分与贡献，以及综合分和排名前后对照。排名页、个股页提供逐行业平均分、残差均值、样本数和覆盖情况；个股页可以选择历史评分日期。

回测页“持仓行业暴露”跟随持仓日期选择，显示实际行业权重、最大行业权重、HHI、现金和未知行业持仓。历史沪深300池提供月度基准行业权重近似及主动偏离：使用当时已知快照，不作每天权重漂移，也不伪装成精确逐日指数权重。其他基准无行业成分数据时显示不可用。换评价基准不会改变策略执行；非沪深300基准不沿用沪深300行业对比。

行业中性化是**因子处理**。TopK选股、费用、整手及受阻退出均由原Qlib执行链处理，不保证实际持仓行业权重中性。本阶段没有加入行业持仓上限或行业约束优化。

## 历史数据和日期边界

官方Tushare账户实测可以获取 `index_classify` 的SW2014/SW2021一级分类，以及旧 `index_member` 和新版 `index_member_all` 的纳入、剔除记录。共获取28个旧分类和31个新分类的Y/N分区，发布15,486条区间、5,923只股票。新接口日期字段及单次2000行限制见[官方文档](https://tushare.pro/document/2?doc_id=335)，分类版本见[分类接口](https://tushare.pro/document/2?doc_id=181)。每个分区小于2000行；触及上限会拒绝发布，不能把截断响应当成完整数据。

新版记录存在回溯至1990年代的纳入日期，不能直接拿SW2021分类用于2020年。本实现采用以下**保守研究约定**，不将其称为精确公告认证：

- SW2014仅在2015-01-01至2021-12-10研究区间使用；更早不提供行业标签。
- SW2021最早2021-12-13使用。切换边界结合旧区间在2021-12-10附近终止的响应证据设定，仍未独立认证实际公告时点。
- 日期粒度的纳入、剔除记录在记录日期后的下一交易日起更新；剔除日期当日保留旧区间。这可能产生保守的一日缺口，明确显示未知。
- 同一级行业重叠记录合并视为同一归属；跨行业重叠标记冲突。缺失或冲突不向前、向后填充当前行业。
- 行情中的下载时基本信息 `industry` 继续兼容展示；历史处理使用独立的 `industry_code/industry_name/classification/industry_status`，不用当前静态行业。
- 超出行业源核验日期后，不继续沿用旧标签；开启任务明确要求刷新缓存。下载时间只作缓存新鲜度上界，**不作为历史公告可知时间**。

2020-01-02至2026-10-30的1653个交易日、495900条当日沪深300成分记录中，494263条有历史行业，1637条缺失，无跨一级行业冲突。392天出现缺失，最少291/300只已知；部分早期科创板股票无旧版记录，另有日期保守延迟造成的单日缺口。2020-01-02、2023-01-03及2026-10-30均为300/300。没有使用新分类或当前行业替它们回填。

以上仅重建供应商所给的历史区间。历史修订、精确公告及盘中发布时间尚未独立认证，所有行业数据保留 `point_in_time_certified=false`。

## 因子处理算法

关闭模式沿用原来的共同有效截面、因子百分位、权重和排名计算；行业映射及暴露只作诊断，不参与选股。

开启模式每天执行：

1. 先按原规则计算原始因子，取所有选中因子、历史资格及行业均有效的交集，不按缺失项重分权重。
2. 统一方向为越高越好，按**当日截面**1%/99%分位缩尾。
3. 减去各行业当日均值，等价于对完整行业哑变量回归后取残差；以当日截面残差总体标准差标准化。
4. 对残差作平均并列百分位排序，再按用户原权重合成，交给原Qlib策略。

处理前得分以同一个有行业的共同有效截面计算，便于隔离处理中产生的变化；若行业缺失导致截面收缩，它与独立关闭任务的全股票池排名可能不同。网页同时显示行业覆盖和缺失原因。

单股票行业残差为0，并明确提示；若当天所有选中因子均无行业内差异，不发布伪有效评分，也不自动关闭功能。有效评分不足时任务按原规则失败并保留原因。权重没有重分配。

标准化残差的行业均值为0；随后百分位是非线性变换，其行业平均分不一定相同。行业残差均值、行业平均百分位和最终持仓权重分别展示，避免混淆。

个别因子IC和相关性在开启时使用方向已统一的标准化行业残差，关闭时继续使用方向统一的原始值；综合分诊断使用实际策略综合分，未来收益标签仍只进入评估。

## 保存、刷新和复现

数据在 `data/industries/official-tushare/`：`raw/`保存原响应分区，版本目录保存区间Parquet及校验清单，`current.json`指向当前版本。初次或中断后运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/check_official_industries.py
```

需要从官方刷新全量历史时：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/check_official_industries.py --refresh
```

请求串行并遵守统一Tushare限频；分区原子写入，已有分区可复用；刷新写入新的原始响应目录，保留旧版本。缓存核验日期取本批最早分区的取得日期，不通过重新发布旧分区伪造新鲜度。未接入BaoStock行业分类补缺。

配置示例：

```json
{"neutralization":{"mode":"industry"}}
```

网页提交时自动固定64位`industry_version`，不必手填。省略配置或`mode=off`沿用原评分；CLI省略版本时解析本地当前版本。代码、处理开关及数据版本进入结果指纹，旧结果不重写。旧结果没有行业诊断时，网页明确提示复用配置重新运行，不用最新行业替旧结果生成看似原生的诊断。

## 验证

独立回归计算验证行业哑变量残差与正交性；测试新旧分类边界、日期变更、未来新增行业不影响早期评分、缺失与冲突、单股票行业、缩尾、权重/窗口生效、版本与校验、串行下载及截断拒绝。

4、8、15只股票覆盖评分计算，4、8只完整执行下载、任务、Qlib和评估；关闭模式成交、持仓及净值完全一致。实际React/HTTP队列完成3只、5只和沪深300动态池各“关闭→开启→关闭”共9组任务，中性化改变成交，再次关闭复用相同结果，并打开本任务评分、回测和处理明细。图表Canvas在DOM验收中替换，未把该检查声称为截图像素验收。

原2023-01-03至2026-09-30的十因子周度长回测，398笔成交逐项一致；持股数量、价格及现金相同。跨进程Qlib汇总的最大净值差为6.7e-16、总资产差5.9e-11元，属于机器精度舍入，未改交易逻辑。

最终585项后端、48项前端及生产构建通过。主服务已运行实际任务“沪深300行业中性化（功能验收）”：2025-03-03至2025-05-30、每周调仓、三因子40%/40%/20%、10只持仓、双边冲击成本0.01%、全收益基准。可打开处理前后明细、切换历史评分日期、查看行业偏离；原成功任务同样可打开。原149个结果/表格/报告文件哈希及活动配置未变。
