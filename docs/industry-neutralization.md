# 历史行业与行业中性化

行业数据用于两类功能：诊断组合行业暴露，以及在因子横截面上消除行业均值。中性化是因子处理，不保证最终持仓权重严格行业中性。

## 网页配置

“新建研究 → 因子配置 → 行业中性化”支持关闭和开启，默认关闭。任务配置保存开关和行业版本；旧任务始终使用原绑定版本。

评分明细展示：

- 历史行业。
- 原始因子和处理中得分。
- 行业残差、处理后百分位和贡献。
- 综合分与排名变化。
- 行业覆盖、缺失和冲突原因。

回测页按持仓日期展示行业权重、最大行业权重、HHI、现金和未知行业。沪深300历史池可以使用同一已知快照近似比较基准行业权重；其他基准没有对应历史行业成分时显示不可用。

## 历史行业规则

系统保存申万一级分类版本和成员纳入/剔除区间，并遵守以下边界：

- SW2014 只用于其配置的有效研究区间。
- SW2021 不用于版本切换前的历史日期。
- 日期粒度的分类变化从记录日期后的下一交易日起生效。
- 同一行业的重叠区间可以合并；跨行业重叠标记冲突。
- 缺失和冲突不使用当前行业前向或后向填充。
- 下载时证券基本信息中的静态 `industry` 不替代历史行业表。
- 超过数据源核验截止日期时要求刷新，不无限沿用旧标签。

这些区间是供应商历史记录，不等同于完整公告和修订首次公开时间，因此行业版本保存 `point_in_time_certified=false`。

## 处理算法

关闭模式按原始共同有效截面计算评分，行业只用于诊断。

开启模式按每个交易日执行：

1. 取因子、股票资格和历史行业均有效的共同截面。
2. 统一因子方向为越高越好。
3. 按当日截面 1%/99% 分位缩尾。
4. 减去各行业当日均值，得到行业哑变量回归的残差。
5. 用当日截面残差标准差进行标准化。
6. 将残差转换为平均秩百分位，按原权重合成综合分。

处理前得分也使用有行业标签的同一截面，便于对比算法影响。行业缺失导致的截面变化单独显示。权重不自动重分配。

单股票行业的残差为零；若所有因子都没有行业内差异，则不发布伪有效评分。标准化残差的行业均值为零，但残差再转换成百分位后，各行业平均百分位不保证相同。

## 配置与复现

```json
{
  "neutralization": {
    "mode": "industry"
  }
}
```

网页提交时固定行业版本。行业开关、数据版本和处理代码都进入结果指纹。关闭中性化应复现同一数据和策略配置下的原始评分路径；开启后因子 IC 使用方向统一的标准化行业残差。

TopK、整手、交易费用、停牌和退出规则仍由原交易执行链处理。若需要约束最终持仓行业权重，应另行实现行业上限或组合优化器，不能把因子中性化当作持仓中性化。
