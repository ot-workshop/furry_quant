# 历史时间口径与日线成交核验

日期：2026-11-02。本次核验不启用动态权重，不重写历史结果，不将无法确认的源数据升级为严格PIT认证。

## 核验结论

| 范围 | 已确认 | 不能据此确认 |
|---|---|---|
| 历史成分 | 本地83期月度快照及其次日生效程序约定；官方样本查询返回月末日期 | 完整调整公告、真实生效日、快照历史首次发布时间 |
| 历史行业 | 新旧申万版本分段、纳入／剔除区间、缺失与冲突不回填 | 全部历史公告及修订的首次公开时刻；切换约定仍不是公告认证 |
| PE/PB | 对应交易日历史值、按日期对齐；抽样与现有归档相同 | 过去每个交易日当时公开的财报版本及完整更正链 |
| 成交 | 当前日频策略信号滞后、停牌、方向性涨跌停、数量、费用及T+1约束 | 竞价排队、盘中价格笼子、实际容量、逐笔分红及完整退市清算 |

这些不是将全系统判为失败，也不是承诺已获完整PIT数据。新结果以独立的temporal_audit保存各项结论，程序约束与历史公开时点认证分开显示。旧结果没有该清单时明确说明缺少本轮记录，不补造认证。

## 已修复的程序问题

1. **固定池单笔数量上限遗漏。** 之前历史动态池使用专用交易所，固定池通用适配未执行同一板块单笔上限。现在在共用适配中限制主板100万股、创业板自2020-08-24起限价模型30万股，科创板专用数量取整仍生效。超过上限的数量保守截断，记录原期望数量；不能等同于自动拆单全部成交。
2. **接近整仓的部分卖出可能丢失余股。** Qlib用默认np.isclose判断清仓，某些大持仓经单笔上限截断后仍被视为全部卖出，未支付的余股可能从账户删除。现在对这种边界保守减少一个可申报单位，保留真实剩余数量并验证财富守恒；不自行重建账户。
3. **估值时点只在停牌检查中覆盖不足。** 因子入口现在检查所用PE/PB／市值的显式日期与可用时间，拒绝晚于信号日或决策时点的输入。未使用的估值字段不阻断纯价格因子；未提供的历史公开时间保留未知，不猜成已认证。
4. **历史载入丢失估值对应日期。** 现在保留原日期字段，并在旧格式需要时结合沿用标记和前值恢复PE观察日期；在完整资产历史中恢复后再截取研究区间，不能把旧值显示为当天新值。无法对账时明确失败，行情值不改写。
5. **信号刚好在开盘时才可用仍被接受。** 现在要求严格早于下一执行开盘；已声明使用收盘数据的真实信号不能被回填为收盘前可用。预先定义的合成信号不被错误当作收盘因子。
6. **行业清单日期声明可被不一致修改。** 读取时除Parquet校验外，还校验版本中已绑定的政策和源核验截止日；不能改清单日期或认证标志而沿用原指纹。旧版本保持兼容。

数量规则依据：[深交所2020-08-21新闻发布会](https://www.szse.cn/aboutus/trends/conference/t20200821_580925.html)、[深交所主板数量规则](https://investor.szse.cn/knowledge/t20230308_599142.html)、[上交所科创板投教说明](https://edu.sse.com.cn/tib/qa/)。本模型是日线开盘成交代理，引用限价申报数量边界不表示已构造真实限价竞价队列。

## 明确保留的限制

- 成分和行业观察日期不等于公告可用时刻；无证据的历史日期不人工猜测或批量“纠正”。
- PE/PB使用供应商日历史值；本模型沿用当日18点可用的假设，不能证明供应商后续未改写过财务分母。
- 当前日频策略每日一次、先卖后买且不对已持仓股票做日内加仓再卖出；股票持有天数检查不是完整分批可售股数账本。
- 冲击成本仍是固定成交额比例，单笔上限不是流动性约束。新增“成交额／此前20日均成交额”诊断只用于报告，不偷偷改变撮合，也不把当日最终成交量用于开盘决策。
- 复权等效持股不是券商逐笔实有股份和现金红利台账；生命周期结束的冻结估值不代表可兑现回收价值。
