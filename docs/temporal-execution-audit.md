# 历史时间口径与成交规则

系统把“程序按过去数据计算”和“供应商证明数据在当时真实可得”分开记录。前者可以通过因果性测试验证；后者需要数据源提供公告、修订和首次发布时间证据。

## 数据时间口径

| 数据 | 使用规则 | 认证限制 |
| --- | --- | --- |
| 历史成分 | 保存月度快照，按下一交易日生效约定进入资格 | 快照日期不等于公告或真实生效时刻 |
| 历史行业 | 使用申万版本边界和纳入/剔除区间，缺失与冲突不回填 | 供应商区间不是完整公告修订历史 |
| PE/PB/市值 | 与交易日对齐，保存观察日期和可用时间 | 历史财务分母和修订首次公开时间未完整认证 |
| 日行情 | 收盘数据最早用于下一交易日决策 | 日线无法重建竞价排队和盘中价格路径 |
| 基准 | 保存价格或全收益序列及其来源 | 基准口径只影响比较，不改变策略交易 |

结果中的 `temporal_audit` 分别展示程序约束、来源证据和认证状态。缺少证据时标记未知，不以当前数据倒推历史认证。

## 信号与执行

- T 日收盘信号只能用于 T+1 的交易机会。
- 可用时间必须严格早于执行开盘；刚好在开盘时才可用的值拒绝使用。
- 修改未来价格、估值或复权不能改变此前评分和成交。
- 开盘价缺失、非有限或非正时不回退到当日收盘成交。
- 全日成交量和收盘涨跌幅不能预先决定当日开盘订单。

## 交易规则

- A 股按交易板块和日期应用整手、最低申报数量和单笔数量限制。
- 停牌、方向性涨跌停和现金不足会阻止或缩减成交。
- 股票调出历史成分或结束生命周期后每天尝试退出；受阻持仓保留并在后续交易日重试。
- 先卖后买，非调仓日的强制退出不会触发隐藏的日内补仓。
- 交易费用在下单数量确定前进入现金约束，未成交订单不收费。

日线模型不模拟竞价队列、盘中价格笼子、真实市场容量和逐笔分红清算。固定比例冲击成本是压力测试参数，不是市场冲击估计器。

## 财报接入约束

真实财报因子必须提供：

- 报告期 `report_period`。
- 带时区的 `available_at`。
- 公告、更正和重述的版本标识。
- 查询时点可见版本的选择规则。

选择顺序是先过滤 `available_at <= as_of`，再按股票和报告期选择当时可见版本，最后截取历史窗口。只有公告日期而没有时刻时，保守设为下一交易日开盘可用。只有最新修订而没有旧版本的数据不能严格重建过去。

## 复权与公司行动

发布和加载都会检查复权连续性、未复权价格和接口涨跌幅。异常候选不会通过前向填充、未来终点缩放或邻日插值修补。复权等效持股用于研究收益，不等同于券商逐笔股份和现金红利账本。

完整边界还包括退市清算、历史换码、ST 规则和更细粒度交易限制；未建模部分会在结果假设中明确列出。
