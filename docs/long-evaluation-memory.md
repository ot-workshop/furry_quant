## 修改

- 按批读取因子原值并转换成数值列，不同时保留全历史原值字典。
- 收益标签按持有期生成并分批写入Parquet，不在内存累计所有持有期的标签字典。
- IC仍由Qlib计算，输入缩为必要列并以布尔有效性标记替代保留各日完整表；因子相关性逐日计算平均秩的Pearson矩阵，保持同一Spearman口径及常数截面排除规则。
- 标签计算只复制日期、证券、开盘价、复权因子和停牌状态；不复制无关字段。缺失交易日、尾部标签和停牌排除规则不变。
- 内存不足与磁盘满分别提示；其他内部错误保存失败阶段、异常类型和文件/函数/行号。诊断不保存异常参数或局部变量，避免暴露密钥，失败后可复用配置。
