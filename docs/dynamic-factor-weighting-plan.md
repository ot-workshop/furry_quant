# 滚动IC与ICIR动态因子权重计划

状态：P5可选研究增强，设计保留、近期暂不实施。2026-11-02用户要求优先收尾主线；后续顺序见[主线进度与优先级](mainline-status-and-priorities.md)。尚未修改动态权重策略代码、任务配置或已有结果。

## 目标与边界

低PB、低PE使估值类因子得分较高，并不自动说明它们在下一阶段仍有效。动态权重根据截至决策时点已兑现的历史预测效果，对原来的人工权重作有限调整。它是自适应选股研究，不能保证收益、夏普或回撤改善，也不能提前识别风格转折。

现有个别因子IC及Rank IC由Qlib计算，但评估位于回测之后。目前没有可供策略逐日使用的历史权重日程，不能直接将整段事后报告喂回交易。

## 首版配置

| 项目 | 计划 |
|---|---|
| 模式 | 固定权重／滚动平均Rank IC／滚动Rank ICIR |
| 统计窗口 | 21、63、126个交易日及自定义；首轮研究用63日 |
| 预测收益期 | 1、5、20个交易日；首轮研究用5日，与统计窗口分别配置 |
| 调权频率 | 默认随交易调仓周期；可选日、周、月，IC每日结算 |
| 人工基准权重 | 沿用用户现有因子权重，参与混合并用于异常回退 |
| 动态占比 | 首轮研究50%；0%退化为固定权重 |
| 有效日期 | 至少覆盖窗口80%的IC到期日，并满足最少观测及非零方差 |
| 单日横截面 | 默认至少30只有效股票，可配置；小池明确提示不稳定或无法动态调权 |
| 负IC | 动态评分部分置0，首版不自动反转因子方向 |
| 集中及变动限制 | 可设单因子上限与每次最大变动，首轮可用5个百分点变动限制；因子数少时先校验约束是否可行 |

上述为预先固定的研究起点，不称为已优化参数。21日窗口反应快但样本少；不依据2023—2026的已知收益挑选“最佳窗口”。

## IC口径和权重算法

1. 在每个历史信号日S，用当时实际可选、所有配置因子共同有效的股票，计算方向统一后的个别因子值。行业中性化开启时使用当时的行业残差，关闭时使用原值；与实际评分的处理模式一致。计算个别因子IC不依赖综合分，避免循环。
2. 使用现有标签口径：S日信号，S+1开盘进入，S+1+h开盘结束，以复权收益作为标签。标签不因页面切换价格／全收益基准而变化。
3. 复用Qlib的Spearman Rank IC；同时保存Pearson IC供诊断。滚动Rank ICIR=有效日Rank IC均值／样本标准差，首版不机械年化。
4. 窗口以标签成熟日计：截至决策时点，最近L个交易日内到期的IC，剔除无效点并显示实际信号日范围。不能为了凑够L条有效记录无限向前延伸。
5. 将正的滚动平均Rank IC或Rank ICIR作为动态评分，适当限制极端值后归一化，得到动态候选权重v。ICIR接近零方差时标记不可用，不制造无限权重。
6. 与人工基准权重b混合：u=(1-λ)b+λv，再用上一期权重及集中／变动约束求出最终权重。非负、合计1、单因子上限、每次变动限制必须一并满足，不能逐项裁剪后随意归一化。
7. 全部动态评分非正、样本不足、IC无定义等情况回退到预定基准目标并按约束过渡，记录原因；不会悄悄翻转方向、缩短窗口或换训练股票池。完全没有统计历史时直接使用基准权重。

基准权重与约束必须相容。单因子选择没有重新分配意义；少因子且上限导致权重被完全固定时，要明确提示，不能声称模式必然改变结果。运行时动态权重允许0，不直接塞回要求严格正权重的现有FactorSpec。

5日、20日标签按日计算会重叠。ICIR用于描述历史效果稳定性，不视作独立样本显著性；验收增加非重叠标签对照。IC不包含交易费用、完整涨跌停限制及实际退出规则，最终结论以Qlib净值、费用、换手和风险为准。

## 可得时点和预热

- 决策日在T日收盘后计算。只有退出价格在T日决策时点之前已可得的标签才能结算IC，权重用于T+1及之后的实际交易。
- 按现有标签，h=5时，S日预测的收益至S+6开盘才兑现，不能在S或S+1调权时使用。按当前日线假设，保守在退出日行情可用后入账，保存明确的label_available_at及weight_available_at。
- 每条IC保存信号日、进入日、到期日、可用时点、股票数、缺失原因及计算版本；每次调权保存训练区间、最后成熟标签、有效样本、指标、候选／实际权重及生效交易日。
- 使用S日已知股票池计算S日IC。以后退出指数的股票不能从以前的训练截面删除，标签跨越后续调出仍按预先定义计算；缺失、停牌或生命周期结束导致不可计算时保留覆盖诊断。
- 历史加载不仅要提前价格日期，还要扩大股票代码并集及成分日期范围，包含训练时期已退出、正式交易时期不再入选的股票。
- 预热改为同时覆盖因子计算历史、IC统计窗口和预测期。以126日因子、63日统计窗口、5日标签为例，约需195个交易日的前置行情，最终按实际日历和成熟规则推导。
- 最早2020年前后可能有价格预热，却没有足够更早的历史成分记录；不能把2020成分倒填2019。明确选择基准权重启动、延后动态启用，或另行补齐可验证的历史成分。
- 当前月度成分可知时间及估值修订限制继续保留，动态调权不能使这些数据自动获得精确PIT认证。

## 接入顺序

1. **因子值与历史IC结算。** 提取可复用的个别因子观测，扩展预热与历史股票池读取；按可用时点维护IC账本。先不参与交易，独立核对数值与标签边界。
2. **动态权重与原生回测。** 增加独立WeightingConfig，构造逐日权重日程；按当日实际权重合成信号，继续使用现有Qlib执行。关闭或动态占比0复现原评分、成交和净值。
3. **网页和审计。** 配置窗口、预测期、调权频率、混合比例和约束；展示滚动IC／ICIR、权重曲线、当日原权重／实际权重／分项贡献、训练截止日和回退原因。IC正常更新不代表当天一定调仓，页面分别展示调权与交易日期。
4. **固定方案对照和时间滚动验证。** 相同数据、因子、股票池、行业处理、费率、TopK和调仓频率下比较固定权重、滚动Rank IC、滚动Rank ICIR。调参用开发／验证段，规则冻结后评估测试段；测试段权重仍可按既定规则使用已经成熟的新样本更新。

因子观测、IC账本和权重日程独立缓存，按真实依赖进入指纹。结果同时保存人工基准权重和逐日实际权重；股票明细的权重、贡献及综合分按所选日期返回，不能仍显示固定metadata.weights冒充动态权重。旧结果兼容读取。

## 验收

- 独立计算Rank IC、均值、标准差和权重；构造明确有效／失效的因子样本验证模式差异。
- 修改未来价格、未来行业或未来成分，扩展回测结束日，均不改变早期已生成的权重、排名与成交。
- 测试跨周、跨月、长假、标签未到期、样本不足、全负IC、零方差、单因子、少股票和不可行约束。
- 多个任意固定池及历史动态池，分别验证窗口、预测期、基准权重、混合比例和调权频率实际生效；不足则明确回退，不伪装成功。
- 静态模式及动态占比0复现旧执行；切换展示基准保持动态权重、成交和策略净值一致。
- 检查净收益、回撤、夏普、行业暴露、换手和实际成本，不能仅凭ICIR提高宣布策略改善。
- 已反复查看的2023—2026结果属于回溯研究，不能重新包装成完全未见样本；最终有效性需要后续前向模拟。

## 后续扩展

首版验证后，再评估多窗口混合、相关因子分组上限、正则化的相关性修正和单因子选择性中性化。自动反向因子、复杂机器学习择时和未经正则化的最大ICIR优化不作为首版默认。
