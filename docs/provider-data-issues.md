# 第三方历史复权数据问题

实测日期：2026-10-18。这里只记录已观察到的接口返回，不推断供应商内部实现，也不包含密钥。

五股2025-01-01至2026-09-30的日线和复权数据补齐后，出现30处单日复权收益异常。示例：

| 代码 | 日期 | 接口返回adj_factor | 相邻记录 |
| --- | --- | --- | --- |
| 600000.SH | 2025-11-05 | 1.0 | 前后交易日均约16.5935 |
| 000001.SZ | 2025-02-07 | 0.9495071303791796 | 附近正常记录约127.7841 |
| 600036.SH | 2025-03-05 | 0.9344038834423534 | 前后记录约6.0581 |

同一序列中因子量级不一致。以浦发银行为例，原始股价仍在11元附近，但按这些因子转换会产生接近-94%和随后十余倍的复权收益跳变。对以上三个日期按`adj_factor(ts_code=..., trade_date=...)`重查，仍返回表中值。因此仅按日补抓不能保证口径正确。

原始证据在本地`data/managed/raw/`，候选标准文件和拒绝报告在`data/managed/quarantine/4c29186aad4dc350/`。涉及的错误试算已隔离在`runs/archive/`，结果API不展示。程序不会把因子自动乘以未来终点比例，也不会以邻日填充值来掩盖异常。

需要数据方提供同一标的、整个历史区间内口径一致且来源明确的累计复权因子，或提供经过核实的公司行动/复权价格。当前保留`configs/research.two-year.json`用于复测质量拒绝流程；它不是已通过验收的多年研究案例。

有效工程案例另用`configs/research.verified.json`：五股2026-02-02至2026-09-30。其日期、字段及连续性检查通过，但没有独立对照交易所逐条验真，财报历史修订也未验收。
