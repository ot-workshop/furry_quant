# 因子研究基础

本阶段让“因子参数 → 评分 → Qlib 回测 / 因子评估 → 结果报告”形成可复查流程。图形化配置、网页任务提交、财报与机器学习模型尚未实现。

## 使用

准备好本地数据后，无需联网或再次下载：

```powershell
.\.venv\Scripts\python.exe -m finance_quant.cli real --config configs\research.verified.json
.\.venv\Scripts\python.exe -m finance_quant.cli evaluate --config configs\research.verified.json
.\start.ps1
```

配置模式启动时会生成或复用上述两类结果。网页新增“因子评估”，可以切换已保存批次和持有期、查看统计及覆盖率、下载 JSON 和 Markdown。

评估命令本身不运行交易引擎，也不改变激活的回测配置。回测和评估共用评分批次；交易资金/费用变化不会使同一批因子重复保存，评估持有期变化不会改变回测。

## 参数

在现有配置中添加可选字段，省略时保持默认值：

```json
{
  "factors": [
    {"name": "momentum", "weight": 0.4, "window": 20},
    {"name": "value", "weight": 0.3},
    {"name": "volatility", "weight": 0.3, "window": 10}
  ],
  "evaluation": {"horizons": [1, 5, 10], "groups": 3, "min_cross_section": 3}
}
```

以上是新增字段示意，仍需原配置的 `data`、`backtest` 和输出目录等字段，完整例子见 `configs/research.verified.json`。

- 只接受已登记的动量、盈利收益率、波动率，不接受任意代码或表达式。可只选择其中一个或两个。
- 每个入选因子权重必须为正，合计为 1（数值容差 1e-9）；删除不参与的因子，不用权重 0 表示关闭。
- 动量和波动率窗口为 2–252 个交易日，默认 20、10。估值使用当日正 `pe_ttm` 的倒数，没有窗口；缺失或非正值不参与。
- 百分位按入选因子均有效的交集股票池计算；动量与盈利收益率越高越好，波动率越低越好。原始值、分数、窗口、权重与方案均保存。
- 若不选择估值，缺失估值不会阻止纯价格因子评分。真实财报因子未接入。
- 持有期为互不重复的 1–252 个交易日。分组数为 2–10，最少横截面至少为 3 且不小于分组数。股票池不足时保留缺失统计，不凑数。
- 评分仍需历史预热；较长窗口可能需要更早的数据。错误字段、重复因子、布尔数值和非有限数在运行前拒绝。

## 时间与收益口径

T 日评分假设在上海时间 18:00 可用。评估只选择下一交易日开盘入场日期位于 `backtest.start` 至 `backtest.end` 的信号。持有 h 个交易日，标签为：

`复权开盘价[T+1+h] / 复权开盘价[T+1] - 1`

先按交易所日历对齐，再移动日期；缺少某日行情不会缩短持有期。离场日必须不晚于评估结束日；尾部不足、入场或离场价格缺失时不填充。收益标签仅进入事后评估，不交给因子或 Qlib 策略。

IC 为方向调整后原始因子和收益标签的 Pearson 相关，Rank IC 为 Spearman 相关，均复用 `qlib.contrib.eva.alpha.calc_ic`。波动率取负值对齐方向，综合分直接使用已保存分数。

横截面样本不足、因子常数或收益常数时，相关系数为 `null`；均值只使用有效日期。IR 为每日相关均值除以样本标准差，不年化；标准差为零或样本不足时为 `null`。不提供把重叠标签当独立样本的显著性结论。

分组使用原始方向分数的平均秩百分位；Q1 最低、末组最高。相同值不按代码拆散，各组允许不等大或为空；两端组齐全才计算高减低。组内股票等权，各日期平均等权。多日标签可能重叠，因此不连乘分组收益生成净值。分组收益没有费用、涨跌停或成交约束，不能当作可交易策略收益。

因子相关性为逐日横截面 Spearman 的平均值，使用同一方向和股票交集，附有效日期数。

## 版本与产物

- `runs/factors/{id}/result.json`：评分；ID 绑定冻结数据、因子选择、窗口、权重、源码、依赖和 Python 版本。
- `runs/evaluations/{id}/result.json`：逐日 IC、各组收益/数量、标签、覆盖与排除原因、相关性、方法和来源。
- 同目录 `report.md`：可独立阅读的报告，与下载接口一致。
- 评估 ID 绑定评分批次、区间、评估参数与代码。相同输入复用；变化产生新批次，禁止静默覆盖。
- 计算与结果发布使用文件锁，JSON 和 Markdown 分别原子发布。中断后重跑可补齐报告；网页报告只从完整 JSON 生成，HTTP 请求不执行研究计算。

只读接口为 `/api/v1/evaluations`、`/{id}`、`/{id}/download`、`/{id}/report`。
