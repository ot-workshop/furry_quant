# 官方主源与辅助抽样（2026-11-01）

此规则用于沪深300历史仓库下载，替代此前每只股票必须通过双源核验的要求。固定池旧研究入口、已发布历史结果不自动改写。

## 三种通过状态

| 状态 | 含义 |
| --- | --- |
| `single_source_passed` 单源检查通过 | 官方价格、复权、交易日和必要字段内部检查通过；未完成独立价格与复权认证 |
| `dual_source_verified` 双源核验通过 | 官方保留，BaoStock完整区间通过自身检查，并完成原价和复权收益核验 |
| `secondary_fallback_passed` BaoStock补缺通过 | 官方行情或复权存在异常，经严格核验后使用BaoStock整只股票完整区间行情和相对因子；估值及涨跌停仍由官方提供 |

每份逐股收据、资产索引和每一行行情都保存`validation_level`；网页分别显示数量。完整仓库通过检查不等于全部双源认证。缓存和校验代码指纹隔离，更新规则后复查已有原始捕获，旧资产及隔离证据不覆盖。

## 何时调用BaoStock

- 正常完整官方数据直接保存。使用`SHA256(股票代码) % 10 == 0`固定抽样，约10%；与股票排序、批次、重启无关，不是仅测固定几只。
- 缺报价、停牌疑点、价格/复权异常或估值记录缺口触发额外检查。优先用官方`suspend_d`逐日全天停牌记录解释缺口，明确排除盘中停牌；官方状态不可用时才依赖BaoStock原始和复权表覆盖完整日历且一致的交易状态。不能凭缺口推断停牌，确认后才允许按此前报价估值，成交量为零。
- 交易状态证据与复权价格证据分别评估：BaoStock错误复权价格不影响其已独立核实的停牌状态，但该状态证据不升级为双源价格认证。
- 抽样时辅助源连接失败、达到配额或内部数据不一致，可保留自检通过的官方数据，标记单源及未核验原因；依赖辅助源才能解决的异常仍不得发布。
- 若两个有效来源给出明确冲突，继续隔离。不会把冲突当作来源不可用而跳过。
- BaoStock保持全局串行、每日10000条SDK消息预算与分钟限频；没有并发下载、绕过封禁或重置计数。

官方自检覆盖日期完整、重复、正价格、OHLC几何、成交活动、参考收盘与报告涨跌幅、复权收益、成分期执行价格字段、停牌沿用和生命周期。PE亏损缺失属于因子覆盖，不填造PE。特殊大涨跌仅按此前已公开且精确到日期的事件记录审核，保留原始价格及无日涨跌幅限制标记。
