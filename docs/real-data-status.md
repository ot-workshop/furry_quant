## 多年验收未通过的原因

已尝试取得五股2025-01-01至2026-09-30的数据，共424个交易日、2120条日线。按区间返回的复权因子大量漏行，实际按日补抓后日期虽齐，仍发现30处异常单日复权收益跳变，显示同一序列中存在不同尺度的因子。对部分异常日期重新调用同一接口，仍返回相同异常值。

该候选`4c29186aad4dc350`已移至本地`data/managed/quarantine/`并标记拒绝；错误试算`5165bca4fdb3`移至`runs/archive/`，不再从结果接口展示。历史数据不做自动缩放或前向填充以消除异常。多年实数回测尚未验收，需要数据方纠正或独立可靠来源核对；详情见[问题证据](provider-data-issues.md)。

发布前、回测加载前均检查复权连续性：单日复权变动超过50%，或与接口涨跌幅偏差超过5个百分点时，要求核查数据/公司行动。这是当前支持范围的保守审计阈值，不是交易所涨跌停规则。跨年流程有离线测试，不代表真实多年数据已合格。

## 接口与处理口径

日线、交易日历、复权、每日估值、涨跌停、指数和股票基本资料均已实测。`fina_indicator`按日期范围可以返回记录，VIP接口曾返回不存在；财报历史修订未核实，本次不使用财报因子。

- 股票和指数成交量由手转股，金额由千元转元，总市值由万元转元。
- 官方日历决定时间轴；缺失、多余、重复、非正执行价格或复权/限制价缺失会阻止发布。
- 价格和限制价乘`adj_factor / first_adj_factor`，成交量除以同一比例；不以前方未来终点作归一化基准。
- Qlib按复权收益/等效持股记账，输出转换为原始价格及等效股数，不等同于券商逐笔现金分红账本；策略与价格指数基准存在分红口径差异。
- 日线和每日估值假设当日18:00可用，下一交易日开盘执行；供应商历史实际发布时间和修订尚未经审计。
- 买入涨停/卖出跌停使用开盘价及对应限制价；不使用当天收盘涨跌幅或完整成交量决定早盘订单。
