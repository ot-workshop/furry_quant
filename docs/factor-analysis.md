# 因子分析与方案比较

## 先分清比较的指标

| 入口 | 数字含义 | 空值时先检查 |
| --- | --- | --- |
| 回测详情 `/backtests/<id>` | 策略净收益、年化收益、风险与费用 | 对应回测的 `metrics`、净值和执行记录。 |
| 因子评估 `/evaluations/<id>` | 因子 IC、Rank IC、分组平均收益 | 原始因子观测、持有期收益标签、有效截面和数据绑定。 |
| 方案比较 `/experiments/<id>` | 分段选优或同区间收益来源对照 | 比较任务是否完成、各候选/分段的回测与覆盖。 |

“盈利收益率”是因子名称，不是策略总收益。单因子统计为空并不自动意味着回测总收益缺失；比较列表为空也不等于已有回测无法计算。报告问题时给出运行 ID、页面路由、持有期、因子或候选名称及具体空缺字段。

例如入选盈利收益率因子却未绑定财务版本，可能没有真实原始观测。缺失赋分不进入单因子统计，IC 和分组收益应保留为空；不能用 0 补齐后与其他因子比较。先检查[财务状态与绑定](financial-data.md#研究绑定)，准备覆盖研究期的财务数据并重新评估，再核有效样本。没有足够样本、标签或截面时，重跑后仍可能为空。

## 选择因子与查看覆盖

在“新建研究”的因子名称旁，或“方案比较”的因子选项旁，悬停、聚焦或点击信息图标可以查看说明并核验覆盖。确认存在缺失数据后，图标显示为黄色圆形感叹号；数据完整或尚未核验时使用信息图标。

提示包含因子定义、按当前股票池和窗口计算的覆盖数量及主要原因。盈利收益率区分原始值可用、缺失或受限，以及盈利、零利润、亏损股票数；缺失评分按所选方式处理。统计日期为回测开始前的一个交易日，只使用当时已可用的资料；修改股票池、筛选条件、起点、窗口或缺失处理方式后重新核验。数量表示该日该因子的独立覆盖，整个区间内可能变化，组合还受其他因子和交易条件约束。

缺失或受限可能来自非正市值/PB、停牌、预热不足、当时无可用财报、财报过期，或必要字段/TTM历史无效。亏损和零利润不属于盈利收益率缺失。毛利率行业不适用固定记50分，单独计数，不视为普通下载缺口。原始缺失值不填零；盈利收益率和毛利率的真正缺失可以记0分、记50分或剔除，其他因子继续严格处理。数据不可读取时显示核验失败及重试入口，不把未知覆盖显示为零缺失。

## 查看因子诊断

完成研究任务后，从任务中心打开“因子评估”，也可以从评估列表选择已有结果。

1. 在页面上方选择收益持有期。例如 5 个交易日表示 T 日收盘后评分、T+1 开盘入场、再经过 5 个交易日于开盘退出。
2. “因子诊断”查看整体 IC/Rank IC、IR、分组平均收益和有效日期。
3. “证据体检”只读核查单个因子或综合分在指定信号日期范围与截止日（`cutoff`）下的可用性、填补/不适用分离、标签覆盖、财务绑定状态，以及基于冻结信号交易日位置的 Newey–West（Bartlett 核）Rank IC 均值与 95% 近似置信区间。
   - **成熟与截止日约束**：仅纳入退出日为合法 `YYYY-MM-DD` 且不晚于 `cutoff` 的有限 Rank IC；有入场日记录时同时校验 `信号日 ≤ 入场日 ≤ 退出日`，缺入场日时校验 `信号日 ≤ 退出日`，缺失退出日或异常日期不推定成熟。
   - **缺口与门槛**：均值对 `n` 个有效成熟日等权；令有效日 `z_t = Rank IC_t − 均值`、缺口 `z_t = 0`，`S = Σz_t² + 2Σ(k=1..L)[1 − k/(L+1)]Σz_t z_(t−k)`，求和按冻结信号交易日位置对齐（`z_t` 缺口不计入样本量 `n`，`L=0` 时无滞后配对）。默认 `lag = 持有期 - 1`（可选 `0..251`），样本门槛为 `n ≥ max(20, 2(L+1))`，不自动缩短滞后；无日历或零观测时区间与均值留空，样本不足或方差退化时有定义的描述均值仍可展示、区间留空。
   - **覆盖与未知**：交易日数与股票·日数分别列示；仅当筛选范围内全部信号日均保存该字段时才返回全区间总数，缺日期、缺因子或旧字段缺失时保留“未知”，不回填为 0。标签覆盖沿用原评估截止日下的冻结汇总，而 `cutoff` 仅约束 Rank IC 与进入 IC 的配对观测。
   - **区间含义限制**：95% 近似区间（`均值 ± 1.959964 × sqrt(S / [n(n-1)])`）仅反映历史有效日均值的估计不确定性，不代表未来收益或因果关系，也不消除反复筛选因子带来的选择偏差。
4. “时序分析”选择因子或综合分，设置回看窗口与最少有效日期。窗口接受自定义交易日数，20、60、120 日提供快捷选项。
5. 可选择信号日期范围。滚动统计先在原评估区间计算，再截取展示范围，因此之前的记录仍可作为窗口历史。
6. 查看每日曲线、滚动均值、滚动 IR 和累计 IC。累计 IC 是信息系数之和，不是策略累计收益。

Rank IC 使用因子排名与未来收益排名的相关性；普通 IC 使用数值相关性。IR 为每日系数均值除以样本标准差，未年化。

### 缺失值和时间

窗口按信号交易日推进，整天没有有效评分时也占用窗口。默认要求窗口内每个日期都有效；可以调低最少有效日期，但应同时查看样本数。有效数不足或标准差为零时，均值/IR 的相应字段显示为空，而不是零。

横轴为信号日期，IC 需要之后实现的收益才能计算。“最早可知日期”是窗口内使用的标签中最晚退出日期。例如 20 日收益标签在持有期走完前不能用于当时的权重选择。当前诊断仅用于历史研究，不参与选股和成交。

多日标签可能相互重叠，因此未把这些统计当作独立样本显著性检验。分组收益也没有模拟费用、涨跌停和实际退出约束，应与可交易回测一起观察。

## 查看因子相关性

“因子相关性”衡量不同因子之间的重复程度，与因子对未来收益的 IC 分开解释。

- 热图使用每日截面 Spearman 相关的区间平均值，色阶固定为 −1～1；蓝色为负相关，橙色为正相关，中间色接近零。
- 空白表示没有有效样本；常数因子不会被填成零相关。
- 点击单元格或使用两个因子选择框，可以查看该因子对的历史相关性。
- 日期范围会重新计算热图和表格的区间统计。
- “平均绝对相关”先对每日相关取绝对值再求平均，用于发现正负时期互相抵消后仍然很强的重复暴露。
- 相关性使用方向对齐后的因子；开启行业中性化时使用处理后的值。

## 筛选因子组合

在“因子相关性”的平均秩相关矩阵下方打开“组合筛选”。候选为当前评估中的单因子，综合分不作为候选。

1. 选择持有期和统计日期范围，再设置因子数量、最低平均 Rank IC、最低 Rank IC IR、平均绝对相关上限及最少有效日期。
2. 设置推荐截止日。IC/IR 只计算退出日不晚于该日的收益标签；截止日后的标签和相关性记录不参与推荐。
3. 点击“筛选组合”。先剔除样本不足、IC/IR 未达标的因子；再移除有更优替代且不损失可行搭配的候选；最后通过 MILP 在满足数量和相关性约束的组合中最大化单因子平均 Rank IC 的加总。
4. 查看各步数量、每个因子的 IC/IR、最晚标签日期和未入选原因。没有可行解时显示最多可选数量，不自动降低门槛。缺少足够相关性样本的因子对不能同时入选。
5. 点击“创建分段比较”。系统带入原行情、股票池筛选规则、财务和行业版本，以及所选因子的原始窗口。推荐组合等权，与原因子组合比较；两者相同时需要另加一个不同方案。

自动建议的三个比较区间全部晚于推荐截止日。后续行情不足时需提前截止日或补齐数据，不能把筛选期当作后续验证期。股票池与推荐组合在该比较中固定；改动来源配置时应重新筛选。创建后仍可调整交易参数和其他候选方案。

热图显示有符号的平均秩相关；组合限制使用每日绝对秩相关的平均值，防止正负时期抵消。IR 未年化，标准差为零时不作有效候选。推荐只筛选因子子集，不优化权重、不反转因子方向；单因子 IC 加总也不是实际组合 IC。各段会重新计算组合评分、覆盖和诊断，随后运行回测。原评估若只保留所有因子的共同有效股票交集，筛选统计也沿用该交集。

比较详情和下载报告保留来源评估、摘要、截止日、门槛及筛选结果。历史数据此前可能已被查看，日期隔离不能消除反复调参造成的选择偏差。

## 收益来源对照

在“方案比较 → 新建”选择“收益来源对照”，或在任务中心从已有研究点击“收益来源对照”，带入原研究的股票池、因子、日期和交易参数。

1. 设置研究区间与共用交易参数。选择基准方案，复制后增减因子、修改窗口或权重，也可以逐方案切换行业中性化和盈利收益率、毛利率的缺失处理。权重须合计100%，不会自动把某个因子的贡献视为独立收益。
2. 勾选“固定相同股票样本”时，同时运行各方案自身可用样本，以及所有方案在每个信号日的共同可评分股票。先限制共同样本，再重新进行百分位排名和行业处理，不是计算完排名后删行。
3. 共同样本只用当日已知的股票池、历史窗口、财报和行业状态。未来上市、成分变化或以后才公布的财报不会决定过去样本；不要求股票全区间一直有效。若共同样本在行业处理后整日无有效区分，则所有方案共同跳过该日。
4. 查看“收益差对照”：独立样本收益差为方案与基准各自回测的净收益之差；共同样本收益差控制候选股票一致；样本变化差额是前两者之差，包含样本、排名和交易的交互影响，不是因果归因或独立可交易收益。
5. 查看两种样本下的策略净值、费用、换手和风险指标。在每日样本覆盖表中打开对应日期的共同样本评分，也可从每一行打开它自己的回测、评分与因子评估。

取消共同样本时只运行各方案可用样本，不计算共同样本收益差或样本变化差额。这里不做验证段选优，属于同区间历史对照。共同候选集合不要求实际持仓相同，受阻退出仍遵守停牌、涨跌停和交易费用规则。旧研究与回测结果保留。

## 分段比较

进入“方案比较 → 新建”，选择已下载的数据范围。

- 自选快照沿用固定池的股票数量限制。
- 沪深300使用历史成分逐日名单；全市场使用所选下载覆盖范围的历史上市、ST 与筛选条件。缺少数据的股票不会被当作已经覆盖。
- 三类股票池共用筛选和行业中性化设置；候选方案只改变因子、窗口和权重，共用行情、财务、行业版本和交易参数。

设置总区间、验证段开始日期和测试段开始日期。开发、验证、测试按交易日首尾相接，每段交易日数须超过最长评估持有期。各候选需要的预热历史会分别检查，可以使用前一分段的历史行情生成信号。

提交后后台先运行所有候选的开发与验证段，按验证段净收益减基准收益选择方案并锁定，然后只运行该方案的测试段。开发段仅供观察，测试段不参与选择。收益标签的入场与离场均须位于对应分段之内，尾部不足持有期的标签剔除。

每个分段独立从相同初始资金和空仓开始，不能拼接为连续策略净值。动态股票池的调入、调出和退出持仓沿用研究回测规则：无法卖出的持仓继续估值并重试；跨分段不承接持仓。

详情页面提供每段的回测、评分和评估链接，并显示逐日股票池数量、有效评分数量范围及有评分的决策日数。候选因子缺失值不同可能造成有效覆盖不同，应结合这些明细比较。

历史成分月度快照、行业历史公开时间、财务与估值修订仍有未认证部分。分段测试不会自动消除这些限制；反复查看测试段再调参，也会使它失去未见样本的意义。
