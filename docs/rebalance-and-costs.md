# 调仓频率与交易费用

固定股票池和沪深300历史动态池共用调仓、成交和费用配置。费率改变不会修改因子评分，但会生成独立回测结果。

## 调仓频率

支持：

- `daily`：每个交易日提供轮换机会。
- `weekly`：每个 ISO 自然周的首个交易日。
- `monthly`：每个自然月的首个交易日。

回测区间首个交易日建立初始组合。节假日使用实际日历中的首个开市日。开盘交易只读取前一有效信号日评分。

`topk` 和 `n_drop` 继续控制排名轮换，调仓机会不表示必然全仓换股。停牌、涨跌停、数量和现金约束可能阻止成交。非调仓日仍每日估值，成分调出和生命周期退出也每天检查；强制卖出后的现金等到下一计划调仓日补仓。

## 费用模式

`legacy` 使用旧的买卖综合费率和最低费用，可额外设置冲击成本。`itemized` 按以下分项扣费：

- 双边佣金：`max(成交额 × commission_rate, min_cost)`。
- 卖出印花税：`成交额 × 印花税率`。
- 双边过户费：`成交额 × 过户费率`。
- 双边冲击成本：`成交额 × impact_cost`。

最低佣金只约束佣金，税费和冲击成本另行相加。未成交订单不收费。买入数量按包含费用后的可用现金重新取整。

网页费率使用百分数，例如 `0.03` 表示 `0.03%`；JSON 和 Python 配置使用小数，例如 `0.0003`。

```json
{
  "rebalance_frequency": "weekly",
  "cost_mode": "itemized",
  "commission_rate": 0.0003,
  "min_cost": 5,
  "tax_mode": "historical",
  "stamp_tax_rate": 0.0005,
  "transfer_fee_rate": 0.00001,
  "impact_cost": 0.001
}
```

## 历史税费

`tax_mode=historical` 使用保存的沪深 A 股分段表：

| 日期 | 卖出印花税 | 双边过户费 |
| --- | --- | --- |
| 2015-08-01 至 2022-04-28 | 0.1% | 0.002% |
| 2022-04-29 至 2023-08-27 | 0.1% | 0.001% |
| 2023-08-28 起 | 0.05% | 0.001% |

早于支持起点的研究会拒绝历史模式，并要求明确选择固定费率。`tax_mode=fixed` 始终使用用户输入，用于成本压力测试，不代表真实历史制度。

## 冲击成本

`impact_cost` 是固定成交额比例扣费，成交报价仍使用日线开盘价，不再重复移动成交价格。它不使用开盘时未知的当日最终成交量，也不模拟实际容量、盘口深度或排队。

实盘前应至少比较多个冲击成本、佣金和调仓频率组合，并同时观察总收益、换手、累计费用、最大回撤和持仓容量。

## 结果明细

回测保存调仓频率、计划调仓日期、费用参数、累计分项费用和逐笔成交费用。旧结果没有分项证据时不会用当前模型倒推历史费用。
