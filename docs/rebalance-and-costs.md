# 调仓频率与分项交易费用

网页“新建研究”的回测基础新增调仓频率；高级设置新增费用模式、券商佣金、税费模式和双边冲击成本。固定股票池和沪深300历史动态池均可用，配置复用、草稿、下载前确认、任务参数和回测结果保存同一套设置。

## 调仓与每日估值

支持`daily`、`weekly`和`monthly`。区间首个交易日建仓；随后分别每日、每周首个交易日或每月首个交易日提供轮换机会。每周按ISO自然周计算，跨年不拆成两个调仓周；节假日采用实际交易日历中的首个开市日。调仓在开盘执行，只读取前一交易日评分。回测从周中或月中开始，首日仍建仓。

`topk`、`n_drop`和现有排名轮换逻辑继续适用，频率设置不意味着每期全仓换股或把所有现有持仓重新调成等权。停牌、涨跌停、申报数量和现金限制仍可阻止成交。非调仓日仍逐日估值，波动率、回撤、夏普和基准仍使用完整日净值。

历史动态池的成分调出/生命周期退出每天检查并重试，不等下个周/月调仓日。卖出受阻时保留持仓；非调仓日成功卖出后，现金等下个调仓日补仓，避免频率设置变成隐藏的每日再买入。当前月度成分快照的时点限制保持原样。

## 费用模式

旧配置默认`legacy`，买入/卖出综合费率与原最低费用继续使用，不额外叠加佣金或税费；旧结果不改写。可以在此模式单独追加冲击成本。

选择`itemized`启用分项费用：

- 双边佣金 = `max(成交额 × commission_rate, min_cost)`。`min_cost`仅是最低单笔佣金。
- 卖出印花税 = 卖出成交额 × 当日/自定义印花税率；买入不收。
- 双边过户费 = 成交额 × 当日/自定义过户费率。
- 双边冲击成本 = 成交额 × `impact_cost`，作为额外费用从账户现金扣除。

综合佣金按包含经手等规费、不含印花税及过户费的口径填写，不另叠加经手费。实际券商若将过户费包在佣金中，可选择自定义税费并将过户费设为0。这里不逐项复刻每家券商的账单或按分取整/日终合并规则。

例：成交额1000元、佣金万3且最低5元、自定义卖出印花税0.05%、过户费0.001%、冲击成本0.1%。买入费用为5+0.01+1=6.01元；卖出为5+0.5+0.01+1=6.51元。税费与冲击成本在最低佣金之外单独相加。未成交订单不收费用。

费用在Qlib原生Account收到成交前计算。买入数量按含费用的可用现金重新取整，保留主板/创业板整手及科创板最低申报数量规则；费用不是事后只修改报告的展示值。

## 历史税费表

`tax_mode=historical`对沪深A股使用已保存的分段表，从2015-08-01起支持；更早日期明确拒绝并提示选择固定费率，不把当前税率回填整段历史。已覆盖历史仓库2020年至今的研究范围。

| 日期 | 卖出印花税 | 双边过户费 |
| --- | --- | --- |
| 2015-08-01至2022-04-28 | 0.1% | 0.002% |
| 2022-04-29至2023-08-27 | 0.1% | 0.001% |
| 2023-08-28起 | 0.05% | 0.001% |

原印花税税率和卖出方征收口径见[税务总局说明](https://tianjin.chinatax.gov.cn/11200000000/0300/030005/20220725150235434.shtml)及[印花税法](https://guangdong.chinatax.gov.cn/gdsw/dgsw_gkwj/2023-03/07/content_48aca236e3e046b88722793056faa9d4.shtml)，2023-08-28减半见[财政部公告](https://www.mof.gov.cn/jrttts/202308/t20230828_3904235.htm)。过户费原表见[深交所2015年答记者问](https://www.szse.cn/aboutus/trends/news/t20150701_518630.html)，2022年调整见[中国结算发布的通知](https://finance.sina.cn/2022-04-28/detail-imcwipii6993883.d.html?wm=3049_0015)及[中国结算大事记](https://m.chinaclear.cn/zdjs/dsj/about_dsj.shtml)。

`tax_mode=fixed`始终使用用户填写的`stamp_tax_rate`与`transfer_fee_rate`，可用于成本压力测试；固定费率不是实际历史制度的声明。历史模式不使用这两个自定义字段。

## 冲击成本的口径

本项目的`impact_cost`是固定成交额比例扣费，用于比较成本敏感性；成交报价仍使用日线开盘价，不再另外移动成交价，避免同一项重复计费。这不是Qlib原始的“当日成交占比平方×系数”容量模型，不以开盘时尚未知的当日最终成交量计算费用。实际冲击、队列、盘中流动性和容量仍需更细数据验证。

费用不进入因子值和评分。相同数据、日期及因子设置，切换频率、佣金、税费或冲击成本复用相同评分/评估，回测生成独立ID；代码、依赖和费用模型版本留在结果中。

## 网页与配置

费率输入单位为百分数：佣金`0.03`表示0.03%=万3，冲击成本`0.1`表示每笔成交额的0.1%。JSON与CLI的费率使用小数。

```json
{
  "rebalance_frequency": "weekly",
  "cost_mode": "itemized",
  "commission_rate": 0.0003,
  "min_cost": 5,
  "tax_mode": "historical",
  "stamp_tax_rate": 0.0005,
  "transfer_fee_rate": 0.00001,
  "impact_cost": 0.001
}
```

这些字段加入原`backtest`对象，其余资金、日期、股票数量等配置不变。旧`open_cost`/`close_cost`在分项模式下保留用于兼容，但不参与扣费。CLI `real`支持相应参数；使用`--config`时仍禁止混用命令行覆盖。历史分段实验继承同样参数，网页公共参数可查。

回测页新增“调仓与交易费用”：显示频率、计划调仓次数、费用模式、参数及累计分项金额；成交记录可展开逐笔费用。旧报告没有分项证据时不倒推虚构税费。

## 验证

专项覆盖跨年ISO周、节假日首个开市日、周中/月中起点、非调仓日强制退出及停牌/跌停重试、现金等待补仓；覆盖2022-04-29和2023-08-28税费边界、最低佣金之外另加税费/冲击、现金不足的科创板1股递减、买入不收印花税及零成交不收费。通过原生Qlib逐日现金/市值对账，修改未来价格和当日最终成交量不改变此前决策/净值。

真实网页联测与独立复算记录存于`.agent-work/execution-web-evidence.json`及`execution-independent-audit.json`；最终全量测试、构建及原服务验收结果见实现状态。DOM联测使用图表替身，不声称额外完成Canvas视觉验收。

本阶段551项全量后端、42项前端及生产构建通过。7组实际网页任务覆盖日/周/月、历史池/固定池、历史税费/自定义税费、佣金及冲击成本改变。独立复算627个账户交易日、530笔成交和3180项费用分项；277笔历史池买入符合已知成分。旧模式与之前真实案例的42个净值点及全部对应成交一致，延长回测尾部未改写早期结果。
