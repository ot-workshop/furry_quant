# 预热与日期校验

滚动因子需要回测起点之前的历史行情。预热数据只用于计算首个信号，不进入回测收益，也不会提前让股票进入历史成分池。

## 自动推算

网页根据回测区间和因子参数计算所需历史交易日：

- `momentum`、`reversal`、`medium_momentum` 使用 `window` 对应跨度。
- 最大回撤需要 `window + 1` 个价格点。
- 成交额异动需要 `window + baseline_window` 个不重叠观察。
- 下一交易日开盘执行还需要信号日与执行日分离。

新建研究页使用所选数据集的真实交易日历，实时显示“最早可回测日期”，并可一键应用。日期选择器只允许选择数据集内的交易日。

下载行情时（数据管理 → 行情下载）可设置“向前预热”的交易日数；预览只查询交易日历与证券资料，确认后才下载。

## 交易日规则

- 回测起止日必须是数据集中的交易日。
- 预热按完整交易日历倒数，不用自然日近似。
- 不使用回测开始后的行情补足回测开始前的窗口。

若预热不足，需要延后回测起点，或重新下载预热更长的行情。

## 提交前检查

任务创建前检查：

1. 交易日历和请求区间完整。
2. 最长因子窗口具有足够预热。
3. 每个回测日共同有效股票数至少满足目标持仓数，且不低于两只。
4. 估值、成交额、停牌和负收益样本满足各因子规则。
5. 已选快照覆盖股票池和日期，不借用快照声明范围外的数据。

失败会返回日期、有效股票数和缺失因子统计，不创建注定失败的研究任务，也不自动缩短窗口或改权重。

## 配置复用

任务中心的“复用配置”会把历史任务的配置载入新建研究页；不再可用的数据集或股票会被明确提示并移除。旧结果和失败任务保留用于追溯。

窗口数量满足并不保证因子一定有效。例如长期停牌可能使成交额覆盖不足，单边上涨可能使下行波动率没有足够负收益观察。这些情况按因子规则显示，不补造数据。
