# 共享行情、范围配置与增量更新

日期：2026-11-02。此阶段提供行情归档和更新，保留既有沪深300仓库、数据快照和回测结果。动态权重未实施。

## 网页使用

进入“数据管理 → 共享行情与增量更新”：

1. 选择沪深300历史成分、全市场（沪深A股）或自选范围，设置起止日期和此前预热交易日数。日期没有2020／2023固定下界，实际可得性由日历、生命周期、成分及接口覆盖检查决定。
2. 小范围测试可填写限定代码。沪深300／全市场留空表示该范围全部股票；自选必须填代码。限定子集会明确标注，不能视为全市场已完整下载。
3. 点击“预览覆盖与增量方案”。预览可查询日历、证券、成分和基准参考资料，但不下载股票行情；页面显示有效区间、预热起点、复用行数、缺口及预计行情请求数。
4. 点击“确认方案并下载／更新”后后台运行。修改任意范围、日期、代码或预热参数会取消旧预览确认；迟到的预览响应不能覆盖新参数。
5. 从任务明细查看新增、复用、待复核原因；支持暂停和续传。成功后保存独立版本，失败不切换上一成功指针。

最多50只、完整覆盖且固定池交易规则支持的版本，会生成“新建研究 → 已有快照”中的官方共享行情选项。它是用户选定的固定池，需要按所选股票重新计算横截面分位，并保留固定池选择偏差说明。新股／退市造成区间覆盖不足、科创板等固定池尚不支持的交易类型只归档，不冒充可以直接固定池回测。

完整且未限定代码的沪深300版本，另外出现在“新建研究 → 沪深300历史成分股 → 历史成分数据版本”。该入口按历史每日成员计算、支持既有科创板动态交易规则。下拉框显示共享版本编号；原493股仓库仍可选择。全市场历史动态回测和大股票池研究的扩展不包含在本轮下载功能中。

## 共享与版本原理

默认位置为`data/managed-joint/shared-market/`（随服务data_root变化）：

- `catalog.json`登记已核验、带来源和校验和的行情分段；现有493股仓库只登记原文件引用，不搬迁或改写。
- `captures/`保存新增缺口的原始响应、SQLite下载记录、标准行情及核验收据。原四类行情接口和质量规则继续复用。
- `plans/{id}/`保存不可变范围、代码、日期、参考数据及进度；同一时刻仅运行一个共享下载进程。
- `versions/{id}/`保存固定来源分段的版本清单，`current/`按股票池定义记录上一成功版本。查看旧回测不读取最新指针替换历史输入。
- `composites/`保存动态研究所需的股票行情组合文件；沪深300研究视图使用同盘硬链接引用它们，成分文件独立于行情。
- 小范围固定池研究投影存放于现有`research/downloads/shared-{version}/snapshots/`，兼容已有研究任务入口。研究投影可能另存选定行，但不会再请求同一份行情。

覆盖按来源、股票、日期及必要字段计算，不由股票池标签决定。`index_member`、预热资格等派生字段不会被带入其他池子。沪深300和全市场的相同股票／日期共用行情，新增日期只抓缺口；跨年缺口分年请求，增量边界最多多取相邻一日核对OHLC和复权尺度。边界冲突保留新响应但不登记为可复用覆盖，更不覆盖旧数据。

单源、双源、补缺等级逐行保留，版本摘要按股票的较弱证据等级汇总。源数据校验通过不等于历史财务或公告时点已认证。官方Tushare的进程共享配额和BaoStock全局串行、每分钟60次／每日10000次消息预算继续生效；本功能没有引入BaoStock并发。

## 时间与覆盖边界

全市场范围从官方L／D／P证券主数据中取区间相关股票，上市前与退市日起不制造行情；包含区间内退市股票，不能用当前上市名单回填历史。当前全市场归档范围为沪深A股，北交所及历史换码映射未适配，页面有明确说明。

成分继续使用月度快照次日生效的假设，完整月份缺快照拒绝规划；未完成月份没有新快照时沿用此前已知名单，不能用当月未来月末名单填充。精确指数公告、行业首次公开时刻和PE/PB财务修订版本仍未认证。

日常增量指补齐尚未覆盖的日期和字段。既有已核验历史分区不会被静默刷新；主动发现并管理供应商对旧日期的更正仍需后续修订流程。全市场计划预计请求数不包括重试、停牌查询、辅助核验和补查，不等于下载耗时承诺。
