# 股票池与条件筛选

动态股票池在每个信号日重新确定选股资格，随后计算因子、排名，并于下一交易日开盘执行。下载范围与研究资格分别管理：同一份共享行情可供固定池、历史指数池和条件筛选使用。

## 网页操作

1. 在“数据管理 → 行情下载”选择沪深300、沪深A股全市场或自选集合，设置日期和预热长度，预览并确认下载。
2. 打开“新建研究”，在“基础股票池”选择沪深300历史成分、全市场或自选股票。数据管理中的“用于研究”会带入对应行情版本。
3. 选择数据版本，查看“实际数据覆盖”中的股票数量、研究日期、预热起点、历史名称和上市日期覆盖。自选股票可从共享行情仓库或已有行情快照中挑选。
4. 在独立的“筛选条件”区域开启筛选，再设置板块、上市天数、ST、市值、成交额和行业条件。三种基础股票池共用相同规则；切换股票池保留筛选配置。关闭时使用基础股票池，不清空已填写的条件。
5. 配置因子、回测日期、持股数、调仓频率和费用，提交任务。
6. 完成后在回测详情的“股票池筛选”查看每日覆盖、通过数量和剔除原因；成交与执行记录显示退出和受阻情况。

限定代码下载会显示为“已下载股票集合”，不能视为完整全市场。已有旧版行情范围尚未包含历史名称参考数据时，在同一范围执行一次增量下载即可生成动态研究版本；已覆盖行情继续复用。首次补充历史名称会产生额外接口请求，预览显示其上限。

沪深300先按历史成分确定基础范围，再在范围内筛选；自选股票先限定用户选择的代码，再进行相同筛选。共享行情中的股票可同时用于这些研究，不按股票池另存、另下行情。自选范围仍可能有选择与幸存者偏差。

覆盖数量表示数据集中存在记录，不代表每个日期都有已公开状态。旧快照没有历史名称或上市日期时，对应覆盖显示不足；可更新下载范围补齐，或明确关闭ST筛选、将上市天数设为0。其他条件仍可使用，系统不会用今天的状态回填历史。

## 条件与单位

| 条件 | 含义 |
| --- | --- |
| 板块 | 沪深主板、创业板、科创板普通A股；不包含北交所、ETF与未适配的CDR |
| 上市天数 | 信号日距首次上市日期的自然日数；上市前不入选 |
| ST | 默认排除历史名称识别的ST和状态未知股票；关闭时明确保留这些候选 |
| 总市值 | 页面单位亿元，使用信号日历史每日估值；缺失值不能通过已设置的市值条件 |
| 日均成交额 | 页面单位万元，按指定交易日窗口计算，包含信号日；停牌零成交不压缩窗口，历史不足不通过 |
| 行业 | 申万一级、二级或三级，可选择多个纳入行业；按该信号日的历史归属判断，留空不限行业 |

行业筛选与因子行业中性化是独立配置。行业筛选限制候选资格；中性化处理因子值，并不保证组合行业权重中性。存在财务因子时复用已下载财务版本，缺失或过期财报仍按因子规则剔除，不能通过重新分配权重绕过缺失。

## 接口与历史口径

- `stock_basic` 提供上市、退市日期，默认流程读取上市、退市和暂停上市证券，避免只用当前上市名单。[官方接口](https://tushare.pro/document/2?doc_id=25)要求2000积分。
- `daily_basic` 提供历史市值、PE、PB，行情提供历史成交额；这些数据与既有下载共享。
- `namechange` 提供历史名称、开始日期和公告日期，2000积分账号可用。历史ST使用名称变更估计，不能标为官方逐日ST认证。[官方接口](https://tushare.pro/document/2?doc_id=100)
- 官方逐日 `stock_st` 要求3000积分，未纳入默认2000积分流程。[权限说明](https://tushare.pro/document/2?doc_id=397)

日期粒度的名称变更，取开始日与已提供公告日中较晚的一天，之后才用于信号。最初没有可见名称时状态保持未知；已有状态仅由之后可见的变更更新。`end_date` 可能事后补齐，不能单独据此提前结束旧状态；较晚发布的更早名称记录也不能覆盖更新的已知名称。这些约束避免使用未来记录，但不等于供应商完整历史发布版本认证。

不根据今天的退市状态删除历史股票，也不利用未来退市日提前清仓。股票结束生命周期后不再入选或交易；仍未卖出的持仓继续保留估值，当前不模拟退市清算。

## 结果与复现

行情版本包含生命周期与历史名称文件的校验值。任务固定行情、财务、行业和筛选配置；历史名称修订会形成不同的数据版本，筛选参数变化会形成不同的研究结果。原始数据和旧回测不会被覆盖。

每日筛选使用信号日及以前的数据，预热不计入回测收益。某日候选不足时记录覆盖并保留现金；整个区间无法形成至少两只有效评分时，任务说明原因。持仓被筛出后每天尝试退出，包括非计划调仓日，遇停牌、跌停或T+1限制时记录受阻并重试。
