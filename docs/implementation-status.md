尚未验收真实涨跌停、停牌、退市、分红送转、历史行业/股票池和财报修订；样本回测不能用于判断策略投资价值。

后续专项检查已将测试增加至 27 项，修正开盘撮合读取收盘涨跌幅等边界，并增加财报可见时点与修订选择函数。详见 [时间边界专项检查](lookahead-audit.md)。财报函数尚未接入真实供应商，不代表真实财报历史已经验收。
