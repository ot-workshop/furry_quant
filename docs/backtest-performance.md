# 回测绩效指标与旧版布局

本次参照旧项目 `stock-process/src/plotter.py` 的 `plot_backtest_summary`：左侧年度收益柱状图、右侧绩效指标表；保留新项目的净值/回撤图、持仓、成交和参数说明。策略与基准并列显示，年度柱状图也包含基准，首尾年度标明实际覆盖日期。

## 指标口径

所有策略收益指标从已保存的**扣费后账户净值**计算。没有再次扣减 `equity.cost`，没有用Qlib的毛收益替代账户收益。首个净值是回测前的本金锚点；若有n+1个连续账户净值，则有n个收益日，年化按n计算。

沿用旧项目每年252个交易日和无风险年利率3%的**研究假设**，并在页面和JSON中明确展示；不是当前市场无风险利率。

| 指标 | 公式 |
| --- | --- |
| 总收益 | 期末净值 / 初始净值 − 1 |
| 年化收益 | (期末净值 / 初始净值)^(252 / 收益日数) − 1 |
| 年化波动率 | 日收益样本标准差（ddof=1）× √252 |
| 夏普比率 | (日收益算术均值 × 252 − 3%) / 年化波动率 |
| 最大回撤 | min(净值 / 此前最高净值 − 1)，含初始本金锚点 |
| 最大回撤日 | 最深回撤首次出现的日期；无回撤时不伪造日期 |
| 卡玛比率 | (年化收益 − 3%) / 最大回撤绝对值，沿用旧项目的超额收益口径 |
| 日收益胜率 | 正收益天数 / 非零收益天数 |
| 日收益盈亏比 | 平均正日收益 / 平均负日收益绝对值 |
| 年度收益柱 | 本次回测在该日历年实际覆盖的日收益复利，包含该年第一个账户日的收益，**不作年化** |

同时展示Qlib保存的日均换手率、费用金额及占初始资金比例、成交笔数、回测交易日数、折算交易年数和策略相对基准总收益的算术差。日收益胜率/盈亏比不等于逐笔买卖配对后的交易胜率/盈亏比。

基准使用同一净值日期和年化口径。基准不完整时不会补零或填充，也不会影响完整策略序列的指标。策略净值缺失、无效或日期乱序时不丢行凑样本，而是显示无法计算。零收益、零波动或零成交保留为0；标准差样本不足、零波动、无回撤或只有单向收益时，对应无法定义的比率为JSON `null`，页面显示“—”。

## 旧结果与版本

- 新Qlib结果直接保存 `performance`、完整数值指标、年度收益和计算口径；指标源码加入真实回测及合成样本的指纹。
- 旧回测无需下载数据或重跑，在列表、详情及下载接口读取时，从该运行自己的冻结净值生成版本为 `daily-nav-performance-v1` 的只读派生指标。
- 旧文件内容、原任务结果ID和交易记录不改写。下载JSON补充 `performance`，并与当前页面的指标一致；这不表示旧文件原来就保存过这些统计。
- 绩效指标只进入事后展示，不进入因子、信号或Qlib撮合。

仍保留原回测的分红口径、费用示例参数、成交约束、股票池选择等限制；新增风险指标不代表策略已通过样本外检验。
