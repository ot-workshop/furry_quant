# 官方全收益基准与独立评价口径

## 数据可得性实测

2026-11-01使用本机现有凭据，强制连接`https://api.tushare.pro`，没有经过第三方兼容服务。`index_basic(market=CSI)`能识别`H00300.CSI`（名称“300收益”）。按年度查询`index_daily`，并与官方SSE交易日历逐日对照：

| 基准 | 核验区间 | 点位数 | 缺失/重复/额外交易日 |
| --- | --- | --- | --- |
| 沪深300全收益 H00300.CSI | 2004-12-31—2026-10-30 | 5300 | 0 / 0 / 0 |
| 沪深300价格 000300.SH | 2019-12-31—2026-10-30 | 1654 | 0 / 0 / 0 |

全收益基日的前收盘缺失，部分日期也不提供OHLC。因此采用独立收盘点位序列，不复用股票行情归一化器、不编造开高低价或成交量。基日1000点仅作锚点，不计算基日前收益。基日到指数发布日前的历史点位不证明当时已经可交易或公开。

Tushare指数日线文档要求2000积分；此处实际账户调用及历史覆盖已通过，但不能将日历完整等同于每条供应商数据都已获独立认证。官方中证资料确认H00300为全收益指数、N00300为净收益指数。

本地数据：`data/benchmarks/official-tushare/<代码>/versions/<序列哈希>/series.parquet`。每个版本保留校验、来源、取回时间与回执；`manifest.json`只是当前版本指针。`availability.json`记录已实测的覆盖区间；后续追加其他日期不自动扩张该历史核验声明。

可复核命令（使用环境或`.env`中的凭据，不将凭据写入产物）：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\check_official_benchmark.py --end 20261030
.\.venv\Scripts\python.exe -X utf8 scripts\check_official_benchmark.py --code 000300.SH --start 20191231 --end 20261030
```

## 网页与配置

“新建研究 → 回测基础 → 评价基准”支持全收益与现有价格指数，固定快照、下载新股票池、历史动态池共用。原下载区的指数标为“行情快照附带指数”，用于兼容原行情快照；评价基准不改变该快照或股票因子。旧任务再用配置时沿用原口径，新选择可保存草稿、下载JSON、排队、复用和打开对应结果。

配置字段：`backtest.benchmark: "H00300.CSI"`，省略或`null`时沿用数据集原基准。

先执行或复用不含评价基准选择的原生Qlib交易结果，再从其固定净值/成交生成独立`benchmark-*`结果。记录`execution_run_id`、所选基准版本、区间序列哈希及评价代码版本。订单、成交、费用、持仓、现金和策略净值完全复用；因子评估不依赖基准，继续复用。Qlib内部原交易基准记录为`execution_reference_benchmark`，所选基准保存在`config.evaluation_benchmark`及独立元数据中。

结果列表保留原交易结果和两个独立评价结果；旧文件不重写。历史结果新增指标只在API读取视图中计算，原始产物保持不可变。基准点位相对回测首日前一个交易日收盘归一化，必须逐日覆盖账户日历。缺口、权限错误或缓存损坏明确报错，不用零收益、前向填充或其他指数替代。已有完整缓存不联网；缺少区间按年串行从官方补取，继续使用全局请求预算。

## 相对绩效

保存并在网页展示策略与所选基准的原有绩效对照、年度收益及以下指标：

- 累计收益差：策略总收益 − 基准总收益，以百分点显示。
- 相对净值收益：策略归一化期末净值 / 基准归一化期末净值 − 1。
- 日主动收益均值年化：mean(策略日收益 − 基准日收益) × 252。
- 年化跟踪误差：std(策略日收益 − 基准日收益, ddof=1) × sqrt(252)。
- 信息比率：日主动收益均值年化 / 年化跟踪误差。

使用相同估值日，不丢弃缺失日；样本不足、零跟踪误差或无效基准时相应比率显示空值。策略夏普、回撤、波动率等只依赖策略净值，切换基准保持一致。全收益基准不扣指数复制费用；策略仍为复权等效持股，尚未逐笔模拟红利税、到账日与真实再投资。

## 验证证据

最终572项后端、46项前端及生产构建通过。主网页已在确认任务与下载均空闲后重载，配置文件不变；原多年回测的价格/全收益两个评价结果已发布到回测列表。125份既有结果与报告文件哈希不变，新结果和原成功任务的页面跳转、绩效、费用及评估打开通过。DOM验收使用图表替身，不声明额外完成Canvas视觉验收。

新增测试覆盖基日、错误代码、非法点位、日期缺口与锚点、缓存损坏、权限失败不覆盖旧版本、强制官方地址、独立指标复算，以及固定/动态池切换时禁止再次调用Qlib仍能完成。

实际React/HTTP四个任务覆盖历史动态池周度和固定池月度，各自切换价格/全收益基准。每组复用同一评分、评估和执行ID，逐项核对成交、订单、持仓、执行事件及全部策略净值；旧任务重开及配置复用通过。见`.agent-work/benchmark-live-evidence.json`。

另将用户原有2023-01-03—2026-09-30多年十因子成功结果复制至隔离验收目录，派生两种基准：908个账户日、398笔成交与原文件逐项一致，原文件哈希不变。基准总收益分别为12.5524%和24.6712%；对两个序列独立复算相对净值收益、跟踪误差和信息比率通过。见`.agent-work/benchmark-long-audit.json`。

行业中性化尚未实现，独立计划见[industry-neutralization-plan.md](industry-neutralization-plan.md)。历史成分公告时点与动态冲击模型也不因接入全收益基准而得到认证。
