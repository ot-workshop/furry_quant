# 价格指数与全收益基准

回测可以使用沪深300价格指数 `000300.SH` 或全收益指数 `H00300.CSI` 评价策略。基准选择只改变比较口径，不改变因子、订单、成交、费用、持仓、现金和策略净值。

## 数据来源

基准点位从官方 Tushare 指数日线获取，并与交易所日历核对。全收益指数使用独立收盘点位序列，不伪造开高低价、成交量或基日前收益。

本地版本保存在：

```text
data/benchmarks/official-tushare/<代码>/versions/<序列哈希>/series.parquet
```

每个版本保存来源、请求区间、取得时间、校验和和覆盖范围。`manifest.json` 只指向当前版本，旧研究继续引用原版本。

刷新或核验命令：

```powershell
uv run python -X utf8 scripts/check_official_benchmark.py --end 20261030
uv run python -X utf8 scripts/check_official_benchmark.py --code 000300.SH --start 20191231 --end 20261030
```

## 配置

```json
{
  "backtest": {
    "benchmark": "H00300.CSI"
  }
}
```

省略字段时使用数据集声明的默认基准。评价基准必须覆盖回测首日前一个交易日和全部账户估值日；缺口、权限错误或缓存损坏会明确失败，不以前向填充、零收益或其他指数替代。

系统先保存固定的策略执行结果，再从同一策略净值派生不同基准评价。评价结果记录：

- 原执行结果 `execution_run_id`。
- 基准代码和数据版本。
- 区间序列哈希。
- 评价代码版本。

切换基准可以复用同一执行结果和因子评估，避免基准选择意外改变交易。

## 相对绩效

除策略和基准累计收益外，系统计算：

- 累计收益差：策略总收益减基准总收益。
- 相对净值收益：策略归一化净值除以基准归一化净值再减一。
- 年化主动收益：日主动收益均值乘 252。
- 年化跟踪误差：日主动收益标准差乘 `√252`。
- 信息比率：年化主动收益除以年化跟踪误差。

策略夏普、波动率和最大回撤只依赖策略净值，切换基准应保持不变。样本不足、跟踪误差为零或基准无效时，相应比率为空值。

价格指数不含现金分红再投资，可能高估相对于持有指数成分股的超额收益。全收益指数包含税前分红再投资，是更严格的长期比较口径；它仍不代表可零成本复制，策略侧也没有逐笔模拟红利税和到账日。

行业中性化、历史成分时点和冲击成本是独立配置，不会因选择全收益基准而自动改变或获得额外认证。
