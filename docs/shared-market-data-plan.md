# 沪深300与全市场共享行情的数据层计划

状态：2026-11-02已实现共享目录、范围／日期预览、增量下载、暂停续传、不可变版本及网页操作，并完成小范围实际下载和回测。使用、验收与边界见[共享行情实现](shared-market-data.md)。全市场批量历史下载尚未启动，动态权重仍暂缓。以下保留设计依据。

## 一份行情，分别管理股票池

沪深300和全市场是不同的股票池定义，共用证券主数据、日行情、复权因子、每日估值、停复牌和限价数据，不各自复制一套下载系统。

- 证券数据按标的、来源、字段集、日期分区和标准化版本存储，下载任务先查覆盖，再获取缺口。
- 沪深300另存带来源与时间口径的历史成分区间；全市场按当日上市、退市、市场和证券类型构造范围，不能用今天在市的股票回填过去。
- 已下载的沪深300股票行情可直接供全市场研究使用；全市场里已有的成分股行情也可供沪深300研究使用。缺少其他股票或更早日期仍需补抓，不能因此声称全市场覆盖已完整。
- “转换为沪深300”指按该历史时点的真实成分条件筛选已有行情，不是把任意股票改个标签变成指数成分。
- 当前仓库的index_member、预热资格等字段是股票池／研究派生结果，不能把它们当作共享行情属性带入另一个池子。

## 下载范围可配置

网页计划提供沪深300历史成分、全市场、自选范围，以及独立的数据开始／结束日期。2023只是已有某次回测的起点；现有沪深300数据仓实际研究范围从2020开始，底层含更早预热。

下载日期与回测日期分别配置，因子预热按所选窗口倒推，不把2020或2023写成所有任务的固定下界。可得最早日期取决于官方接口和本地历史成分证据，不能承诺所有证券都有任意早期数据。

下载前展示预计标的数、已覆盖数量、缺失字段／日期、预热和预计请求量。全市场证券列表包含退市及暂停上市等历史状态，代码变更保留有效期别名。归档范围与回测支持范围分别声明，北交所等未适配交易规则的证券不能在回测时默默套用主板规则。

## 增量、版本和限频

日行情、估值和复权等按可复用分区管理。沪深300任务和全市场任务共用请求缓存、数据校验及Tushare配额账本，BaoStock继续全局串行核验和补缺。按日获取全市场时仍检查接口行数上限、完整性与分页，不能把触顶响应标为全量。

新数据写入待发布版本，检查后切换当前指针；失败继续使用上一成功版本。旧任务固定行情版本、股票池版本、日期和来源校验，不在扩展范围时覆写旧数据或丢失复现依据。不同来源冲突保留证据，不用较低质量的数据覆盖已核验版本。

## 实施顺序和验收

1. 为现有不可变仓库增加共享数据目录／读取适配，先只读登记现有行情，核对原沪深300评分、成交及净值保持一致。
2. 将下载规划与股票池定义解耦，增加任意范围和日期的覆盖检查与缺口计划，保留原入口兼容。
3. 网页提供范围、区间、覆盖、预算、更新和版本选择，再进行少量跨股票池复用验收。
4. 按已确认范围和额度逐批扩大全市场；不在这次核验中直接启动全市场历史下载。

关键验收：沪深300→全市场→沪深300的重叠区间不重复请求；扩展日期只补缺口；新增成分自动复用或补抓；退市股票保留；切池后按实际池重算因子百分位；每次新旧版本与失败恢复均可追溯。
